# AI-example

## Project Name
AI-example

## Project Scope

This is a sample repository for learning and experimenting with AI-powered development workflows. It demonstrates how to integrate:

- **AI coding assistants** (Claude Code) with Git workflows
- **Jira integration** for issue tracking and task management
- **Plan-driven development** using markdown planning documents
- **Automated task execution** through CLI-based AI agents

### Key Features

- Connects to Atlassian Jira for task tracking (KAN project board)
- Uses Claude Code CLI for autonomous development assistance
- Structured planning via `planning/PLAN.md`
- Example repository for AI session assignments

### Repository Structure

```
├── .claude/          # Claude Code configuration and settings
├── .mcp.json         # MCP server configuration (Atlassian integration)
├── planning/          # Project planning documents
│   └── PLAN.md        # Development plan and task tracking
├── README.md          # This file
```

### Getting Started

This repository is part of an AI development learning exercise. It serves as a sandbox for:

1. Practicing AI-assisted code development
2. Learning Git workflow with AI tools
3. Understanding MCP (Model Context Protocol) integrations
4. Working with Jira for issue tracking in AI development cycles

### Technologies

- **Claude Code** - AI-powered coding assistant CLI
- **MCP (Atlassian)** - Integrates Jira with Claude Code
- **Git** - Version control
- **Jira** - Issue and project tracking
